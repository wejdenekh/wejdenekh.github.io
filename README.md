# DevOps Engineer Portfolio

A responsive dark-themed portfolio built with HTML, CSS and vanilla JavaScript. Designed for GitHub Pages.

## 1. Personalize before publishing

Search and replace these placeholders in `index.html`:

- `YOUR_GITHUB_USERNAME`
- `YOUR_EMAIL@example.com`
- `YOUR_LINKEDIN`
- Add your actual CV as `assets/CV.pdf`
- Add your exact employer names, dates and role descriptions
- Add only certifications you have actually earned

Review every metric and technical skill to ensure it accurately reflects your experience.

## 2. Preview locally

Open `index.html` in a browser. No build tools or dependencies are required.

## 3. Publish with GitHub Pages

1. Create a GitHub account at https://github.com
2. Create a public repository named exactly `YOUR_GITHUB_USERNAME.github.io`
3. Upload the contents of this folder to the repository root (not the parent folder).
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then save.
7. Wait for the deployment. Your site URL will be `https://YOUR_GITHUB_USERNAME.github.io`.

## 4. Recommended GitHub repositories

Create separate repositories as you complete and document each project:

- `linux-server-automation`
- `prometheus-grafana-monitoring`
- `gitlab-ci-cd-automation`
- `docker-microservices`
- `reverse-proxy-tls`
- `backup-recovery-runbook`

Do not create empty repositories just to fill the profile. Publish useful, tested content with a clear README, architecture diagram, setup instructions and screenshots.

## 5. Security checklist

Never commit production credentials, private keys, `.env` files, customer data, internal IP addresses, confidential hostnames or employer-owned configuration. Use placeholders and examples. Review files before every push.

## 6. Suggested profile README

A profile README is displayed on your GitHub profile when the repository name matches your GitHub username. Create a public repository named exactly your username and add a `README.md`.
